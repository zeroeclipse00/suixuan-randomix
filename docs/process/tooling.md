# 本地记录工具

## 同步原始记录

`scripts/sync_vibe_trace.py` 使用 Python 标准库，只读本机可访问的 Codex 会话日志。它导出用户与助手可见对话及逐响应用量，不导出系统指令、内部思考或图片数据。

首次使用先在本地创建 `docs/vibe-coding/`，复制 `stage-registry.example.json` 为该目录的 `stage-registry.json`，填写自己的根会话、记录边界和回合阶段。示例占位符必须替换为本地值，配置文件始终保持忽略。

```powershell
python scripts/sync_vibe_trace.py
```

日志目录不同可使用 `--sessions-dir`；配置路径不同可使用 `--registry`。配置必须确认属于当前项目，不混入其他聊天。

每轮开始同步以补齐上一轮最终回复；结束前登记本轮工作并再次同步。当前回合仍在生成时，导出只是注明截止点的快照。

## 导出公开用量

```powershell
python scripts/export_public_usage.py
```

该工具只从本地 `usage.jsonl` 及快照读取数据，按固定字段聚合为公开的 `token-summary.md`。不导出对话、原始文件名、线程、响应、成员或个人路径。缺失字段显示为缺失，不当作零。

缓存输入与推理输出按原始数据的子项口径列示，不重复计入总量。累计 turn/thread 快照不求和；逐响应数据先由同步工具去重。

公开聚合不是费用账单，不代表本轮最终用量，也不包含不可访问的外部工具消耗。应保留统计截止、覆盖范围和未知项说明。

## 手工工作记录

本地人工轨迹和公开 `work-log.md` 均不由同步脚本覆盖。实际产物、功能状态、关键决策、失败修复和验证结果需要按工作编号人工维护。
