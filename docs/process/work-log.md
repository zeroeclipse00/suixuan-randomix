## VC-0003 可运行框架与组员交接

**主阶段：ST-01。** 本轮以框架和环境建设为主，同时实现 ST-02 共享核心与 ST-03 转盘最小流程；不是这三个阶段的完整验收。跨阶段工作保留说明，不按主观比例重复分摊 Token。

### 实际产物

- 建立固定版本的 Kotlin/Compose 工程、官方 Gradle wrapper、Room 数据层和手工依赖容器。
- 实现五类工具的纯领域逻辑与角度映射，建立共享输入校验、请求快照、幂等存储和草稿 CAS。
- 接通转盘候选增删改、明确示例入口、先保存后动画、同结果重试、历史详情与清理；增加减少动画偏好。
- 其他工具与模板显示为独立待开发页面，供队友按模块接手。
- 单独编写开发环境文档和交接说明，准备 Linux/JDK 17 的自动构建工作流。

### 验证与修复

Debug APK 构建通过，26 个 JVM 测试和 10 个 API 35 设备测试通过，lint 为 0 错误、8 条固定依赖升级提示。实际安装启动并检查示例、结果/历史及进程重启恢复。

审阅发现旧恢复结果覆盖新抽取及恢复异常中断订阅的问题，均修复并补确定性回归。实际截图发现小屏主操作不可见，改为固定按钮与自适应转盘。环境中发生转换缓存占用及一次依赖 TLS 中断，保留失败并重试，未删除 SDK 或关闭系统安全软件。

完整条件与限制见[框架验证结果](../testing/framework-results.md)，接手步骤见[交接说明](../handoff.md)。完整工具接入、模板/答案管理、完整无障碍和课程最终交付仍待后续。
