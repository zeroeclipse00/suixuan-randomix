# 随选：模块化任务清单

> v1.1。M00—M12 共 13 个模块。本文是任务规格，不是完成记录；全部 App 任务仍待实施。每个子任务使用“计划/进行中/已实现/已验证/失败/放弃”记录真实状态。

需求见[需求与范围](requirements.md)，共享签名与事务约束见[架构](architecture.md)，验收编号见[验收矩阵](testing/acceptance.md)。子任务交接必须包含输入、相关需求、实际改动和出口证据，不以“页面已画出”替代真实行为。

## M00 对话、工作轨迹与 Token

**优先级/依赖：** P0；贯穿所有阶段，在业务开发前建立。**覆盖：** R13、R14，AC17—AC19。

| 子任务 | 可执行工作与产物 |
|---|---|
| M00-01 | 明确正式记录边界，建立工作编号、阶段编号与任务编号；此前讨论只作背景，不伪造完整用量 |
| M00-02 | 私有保存项目相关可见对话、人工日志和原始用量；排除内部思考、系统指令与无关项目内容 |
| M00-03 | 给主线程及关联子代理调用归属工作与主阶段；原始响应去重，累计快照不直接相加 |
| M00-04 | 每次任务记录目标、实际文件、采用与放弃的建议、失败、修复及验证；区分文档产物和 App 功能 |
| M00-05 | 生成公开脱敏过程摘要、阶段用量表及覆盖说明，用工作/任务编号衔接私有原始证据 |
| M00-06 | 每轮开始/结束同步；当前最终回复和延后用量未到时标明截止快照，后续补齐 |
| M00-07 | 检查公开暂存内容，不上传本机路径、会话标识、账号、原始附件或私人对话 |

**接口/出口：** 输入是本轮真实任务与可获得的来源；输出分为私有详细证据和公开摘要。重复同步不重复计数，未知量不填零；公开摘要能关联实际任务与提交，私有原文仍保留。M00 工具的验证不能计为 App 已验证。

## M01 工程、领域模型与持久化

**优先级/依赖：** P0；依赖 M00，配合 M10 静态设计。**覆盖：** R10、R11、R14，AC01、AC05、AC12—AC14。

| 子任务 | 可执行工作与产物 |
|---|---|
| M01-01 | 检查 JDK、SDK、Gradle、模拟器或真机，记录实际版本及缺项；锁定可构建组合 |
| M01-02 | 创建单应用模块骨架、基础导航与失败界面，提交能构建安装的最小版本 |
| M01-03 | 按架构建立工具枚举、草稿、列表项、模板、答案、请求和结果；实现共用字段校验 |
| M01-04 | 建立 Room 实体/DAO、显式排序、唯一 draw_id、schema 导出和版本字段 |
| M01-05 | 实现草稿/模板/答案整体写入与 expectedRevision 冲突返回；禁止半份列表落库 |
| M01-06 | 实现抽取提交事务、按 ID 查询、历史容量裁剪；P1 会话尚未启动时不预建完整会话 UI |
| M01-07 | 建立业务 Room 与简单偏好边界；启动读取、读写失败和重启行为符合架构 |
| M01-08 | 保存迁移策略，不用破坏性清库处理升级；为事务与故障提供可替换仓储测试入口 |

**接口/出口：** 提供 Draft/Template/Answer/Draw/History 仓储契约；UI 不持有 DAO。退出条件为工程可安装、存储可读写与重启、同 ID 幂等、版本冲突不覆盖、失败无半成品；记录实际命令和设备，不能只凭编译通过宣称数据正确。

## M02 随机引擎与抽取协调

**优先级/依赖：** P0，P1 子任务后置；依赖 M01 领域类型与仓储契约。**覆盖：** R03—R07、R11，选做 R15；AC02、AC04—AC09、AC14、AC20。

| 子任务 | 可执行工作与产物 |
|---|---|
| M02-01 | 实现 RandomSource 与生产/测试组装，非法 bound 拒绝；正式构建不提供固定答案开关 |
| M02-02 | 实现转盘索引、硬币、独立骰子、字母和答案抽样，验证空池、单项及配置边界 |
| M02-03 | 建立 DrawRequest 深复制与结果合法性校验；结果必须匹配同一 draw_id 和工具 |
| M02-04 | 实现转盘角度映射，对每个索引验证实际渲染方向，单项和减少动画直接揭示 |
| M02-05 | 实现 DrawCoordinator：同步关闭入口、生成一次、提交、展示、解锁与旧回调过滤 |
| M02-06 | 注入已知失败/提交不明仓储，验证同 envelope 重试与 find 后恢复，不在重试中再次随机 |
| M02-07 | 验证切后台、返回和重建；提交前中断不宣称成功，提交后恢复原记录 |
| M02-08，P1 | 实现会话剩余池随机、版本检查与事务提交；冲突不自动重抽 |

**接口/出口：** 输入为不可变请求，领域输出结果，协调器输出 UiState。随机函数不操作动画/数据库；动画回调不写结果。通过范围、角度、一次调用、幂等与恢复检查，不以小样本频数替代随机正确性。

## M03 决策转盘

**优先级/依赖：** P0；依赖 M01、M02、M10 基础组件。**覆盖：** R02、R03、R10—R12，AC02—AC05、AC13—AC16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M03-01 | 完成候选输入、列表、等角转盘、主按钮、结果与保存模板入口 |
| M03-02 | 新增/编辑/删除候选，校验规范化重复、长度和 20 项上限；编辑不换 ID，删除重排 |
| M03-03 | 列表变更先保存再更新可抽取状态；失败保留编辑内容并提示重试 |
| M03-04 | 调用协调器完成输入快照、真实随机、提交与展示；列表、扇区、选中 ID 使用同一顺序 |
| M03-05 | 长标签截断但完整结果可读；空池、单项、忙状态和保存失败都有明确反馈 |
| M03-06 | 保存草稿，处理表单离开与取消；套用/保存模板调用 M08，不自行写模板表 |
| M03-07 | 验证四候选编辑后抽取、历史一条、重启草稿保留；再覆盖 1、2、3、7、20 项 |

**接口/出口：** 输入已提交 ToolDraft，输出候选编辑命令和 Draw 事件。先完成“输入—保存—抽取—历史—重启”纵向流程，再精修动效；不能用固定结果绕过存储依赖。

## M04 抛硬币

**优先级/依赖：** P0；M01、M02、M10。**覆盖：** R04、R10—R12，AC05、AC06、AC13—AC16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M04-01 | 设计硬币、清晰的正反面标识、结果文字和“抛一次”按钮 |
| M04-02 | 接入同一协调器及历史，不在动画组件里抽样 |
| M04-03 | 实现有限时长翻转；终点朝向与已保存结果一致，减少动画直接显示 |
| M04-04 | 补齐忙状态、失败、恢复和无障碍文字；重复点击不增加抽样次数 |
| M04-05 | 固定测试源分别覆盖正/反两面，核对文字、视觉、历史和重启 |

**出口：** 两面都能验证，正式运行真实随机，页面重组或恢复不再抛一次。

## M05 掷骰子

**优先级/依赖：** P0；M01、M02、M10。**覆盖：** R05、R10—R12，AC05、AC07、AC13—AC16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M05-01 | 实现 1—3 个骰子的选择，数量先保存；处理中禁用数量变更 |
| M05-02 | 每骰独立生成点数并保留有序数组；总和只由数组计算 |
| M05-03 | 实现 1—6 点阵与文本，动画结束不重新生成点数 |
| M05-04 | 历史保存当时数量和每骰点数，之后换数量不改变旧记录 |
| M05-05 | 覆盖 1、2、3 骰及 1/6 边界，核对点阵、总和、保存与恢复 |

**出口：** 每骰点数、视觉和总和一致，不宣称总和均匀；读写失败不伪装为已保存。

## M06 灵感球与答案池

**优先级/依赖：** P0；M01、M02、M10。**覆盖：** R06、R10—R12，AC05、AC08、AC12—AC16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M06-01 | 提供少量只读默认答案与本地随机说明，不引入联网调用或推理结果假象 |
| M06-02 | 实现自定义答案列表、增删改、规范化重复与数量长度校验；整体保存并增加版本 |
| M06-03 | 实现默认/自定义模式切换及持久化；切换不抽取，两池分别保留 |
| M06-04 | 冻结当前答案池后生成并提交结果，展示揭示动画与可读文本 |
| M06-05 | 自定义空池禁用，单答案直接显示，删除最后一项不回退默认池；编辑取消不写入 |
| M06-06 | 覆盖“散步/听音乐”两答案、修改/删除后的历史不变、模式和重启恢复 |

**接口/出口：** 答案管理通过 AnswerRepository，抽取通过 DrawCoordinator；默认池来源与版本进入快照。结果只来自本次实际启用池。

## M07 字母抽取

**优先级/依赖：** P0；M01、M02、M03 模式结构、M10。**覆盖：** R07、R10—R12，AC09、AC13—AC16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M07-01 | 在转盘页提供“候选项/字母”切换，清楚显示 A—Z 范围 |
| M07-02 | 将字母视为独立工具类型调用统一引擎，使用简短揭示，不强求 26 扇区转盘 |
| M07-03 | 保存为字母历史；切换模式不覆盖候选草稿，也不产生抽取 |
| M07-04 | 测试 A、Z 边界、切换保留、保存失败与恢复 |

**出口：** 字母始终在 A—Z，工具标记正确；转回候选项原列表仍在。

## M08 情境模板与可选会话

**优先级/依赖：** 模板 P0，会话 P1；M01、M03，P1 另依赖 M02 会话逻辑。**覆盖：** R08、R10、R11、R15，AC10、AC12—AC14、AC20。

| 子任务 | 可执行工作与产物 |
|---|---|
| M08-01 | 从已保存草稿创建模板，校验名称与非空候选列表，生成 ID 和首版本 |
| M08-02 | 列表/详情/编辑/删除，编辑以预期版本提交；冲突保留表单并提供刷新 |
| M08-03 | 套用原子替换当前草稿，复制内容并记录来源 ID/版本；脏表单先询问处理方式 |
| M08-04 | 草稿变更后“更新原模板”和“另存为”含义清楚；来源已删除时只允许另存 |
| M08-05 | 可明确导入示例模板，重复导入不静默产生重名模板；应用启动不反复播种 |
| M08-06 | 验证模板后续编辑/删除不改变当前抽取快照或旧历史 |
| M08-07，P1 | 创建独立候选快照会话，显示剩余/已抽，池空禁用，明确重开 |
| M08-08，P1 | 结果与池更新同事务；测试版本冲突、保存失败、重启、模板变化和清历史后会话不重置 |

**出口：** 模板套用不形成共享可变引用，版本与快照可解释；P1 未启动时入口不出现，不能用删除模板选项模拟不重复。

## M09 历史记录

**优先级/依赖：** P0；M01 提交与快照，依赖各工具定义结果。**覆盖：** R09—R11，AC05、AC11—AC14。

| 子任务 | 可执行工作与产物 |
|---|---|
| M09-01 | 按 sequence 倒序查询、分批加载，显示工具/结果/时间/模板摘要 |
| M09-02 | 实现工具筛选、全局空与筛选无结果两种提示；筛选只影响查询，不删除记录 |
| M09-03 | 详情从请求/结果快照显示完整候选、答案或骰子配置；不拼接当前来源数据 |
| M09-04 | 清空前说明范围并确认，处理中不可清理；成功后刷新列表但不重存当前结果 |
| M09-05 | 容量 1000 条裁剪纳入提交事务，验证第 1001 条后只删除最早一条；同时间戳仍有稳定顺序 |
| M09-06 | 验证来源删除、重启、工具切换、读取失败及清空后的旧回调不复活记录 |

**出口：** 每个成功 draw_id 一条历史，失败零条；历史展示与快照一致，清理不波及模板/答案/草稿/会话。

## M10 UI、导航、主题与设置

**优先级/依赖：** P0，分享卡 P2；静态设计无业务依赖，真实绑定依赖各模块。**覆盖：** R01、R11、R12、R16，AC15、AC16、AC21。

| 子任务 | 可执行工作与产物 |
|---|---|
| M10-01 | 按[UI 规格](ui-design.md)建立页面关系、低保真原型、字段和状态图 |
| M10-02 | 固定颜色语义、字号、间距、输入、按钮、提示和结果组件；先做可访问的基础组件 |
| M10-03 | 完成四主工具、字母模式、模板、历史、设置及编辑面板的静态页面，再逐一接入事件 |
| M10-04 | 全部主要入口绑定真实操作；未实现入口隐藏或明确标记，不能只弹“成功” |
| M10-05 | 实现主题、减少动画和上次工具恢复；系统返回、脏表单与键盘行为一致 |
| M10-06 | 检查长文本、大字体、窄屏/横屏、触控区域、色彩区分及读屏描述 |
| M10-07，P2 | 从已保存快照生成结果图并调用系统分享；失败可重试，取消分享不新抽取、不写第二条历史 |

**出口：** 每个状态可操作且可解释，视觉反馈与保存结果一致；减少动画不影响概率，UI 不展示开发账本或内部实现配置。

## M11 测试、集成与问题修复

**优先级/依赖：** P0；从领域与骨架开始持续实施，最终验收依赖全部 P0。**覆盖：** R01—R14，选做启用后覆盖 R15/R16。

| 子任务 | 可执行工作与产物 |
|---|---|
| M11-01 | 维护需求—任务—用例—证据矩阵；用例先有明确预期，再执行 |
| M11-02 | 领域测试覆盖规范化、边界、随机范围、骰子总和、角度和 P1 剩余池 |
| M11-03 | 数据测试覆盖幂等、不同内容同 ID 拒绝、版本冲突、事务回滚、快照、顺序和清理 |
| M11-04 | 自动化验证转盘纵向流程、主要工具和关键错误恢复，人工补充视觉与设备行为 |
| M11-05 | 生命周期与连续操作检查记录设备、条件、动作和实际结果；随机操作可固定测试种子，但不能据此替代正式随机演示 |
| M11-06 | 失败建立问题编号，记录复现、原因、修复与相关回归；不得删掉既定功能换取构建通过 |
| M11-07 | 验收标明未实现/未验证/通过/失败与限制，不把计划清单当结果，也不包装成全基准模型成功率 |

**出口：** P0 需求均有真实结果，无阻断演示问题；构建、功能、稳定性分别有证据。验证命令与设备写进公开脱敏摘要，详细原始材料私有保留。
