## 2. 选题与产品目标

选题使用 [AppForge 任务列表](https://github.com/AppForge-Bench/AppForge/blob/main/tasks/tasks.json)中的 `RandomixDecisionMaker`，中文产品名暂定“随选”。登记使用原任务名，登记表提交由用户处理；公开材料不附登记截图、他人团队信息或成员身份。

[Randomix 原项目](https://github.com/m-i-n-a-r/randomix)仅用于理解需求和交互。若后续引用代码、图形或资源，必须记录具体来源、使用范围和许可证；不能把参考项目的成果描述成本项目已完成的工作。

随选是一款离线随机决策工具箱：输入候选项或选择工具，获得真实随机结果，保存常用情境并查看过去结果。AI 用于协助开发，应用本身不调用大模型；“灵感球”是本地随机答案工具。

Android、Kotlin、Compose 和 Room 是本方案技术选择，课件没有明确强制这些技术，也没有要求 App 内部具备 AI 功能。不声称通过 AppForge 全量原始测试；若课程后续要求原评测，先核对资源 ID、文案和环境，再记录范围变更。

## 4. 业务规则

### 4.1 输入与顺序

- 候选项上限 20 个，单项 1—30 个 Unicode 码点；自定义答案上限 30 条，单条 1—80 个码点；模板名为 1—30 个码点。表单与领域校验使用同一规则。
- 保存前去除首尾空白；同一候选列表或答案池比较时，对拉丁字符采用与区域设置无关的小写形式，内部空格保持原样。保留原显示文本，拒绝规范化后重复项。
- 每项具有稳定 ID 与显式 `position`。列表新增放在末尾，编辑保留 ID 和位置，删除后整体重排；初版不承诺拖拽排序。
- 空候选池禁止抽取并提供添加入口；单项池返回唯一项并直接解释结果，不播放误导性的长动画。
- 模板名称规范化后不重名；更新原模板保留 ID 并增加版本，“另存为”生成新 ID。示例模板只在用户明确导入时创建，不在每次启动时重建。

### 4.2 随机与展示

- 转盘 N 个选项各占相同角度，概率均为 `1/N`。名称、颜色、位置和文字长度不改变概率。
- 硬币两面等概率；每个骰子独立产生 1—6；A—Z 字母等概率。多个骰子的总和不宣称均匀。
- 正式运行使用正常随机源；测试可以注入固定随机源。录屏可以预置候选数据，不固定随机结果。
- 一次操作先冻结输入、生成结果并确认保存，再显示动画。动画不决定结果，减少动画不改变抽样次数或概率。
- 处理中到结果揭示期间禁止第二次抽取，以及会改变本次输入或存储含义的编辑、套用和清理。导航可离开；返回时展示同一结果。

### 4.3 模板、答案与历史

- 套用模板复制到当前草稿。此后编辑草稿不静默覆盖原模板；通过“更新原模板”或“另存为”明确保存。
- 历史保存当时的输入与结果快照，不用当前模板或答案池反查过去。删除模板或答案不删除历史，也不改变旧文案。
- 默认答案只读，自定义答案可以增删改。切换模式本身不抽取；自定义模式为空时禁止抽取，不静默回退默认池。
- 历史按数据库提交顺序倒序显示，时间只用于显示。最多保留 1000 条，超出后在提交事务中裁剪最早记录。
- 清空历史需确认；不清模板、草稿、自定义答案或抽签会话。当前画面可保留结果，但不能重新入库；重启后只恢复仍存在的记录。
- 未保存表单离开时提供“保存后离开/放弃/继续编辑”；保存校验失败则停留。取消编辑不写数据库。

### 4.4 可选抽签会话

不重复模式从模板快照建立独立会话，剩余池不能通过删除原模板选项实现。结果提交和剩余池更新必须原子完成；池为空时本轮结束，用户明确重开才恢复全部选项。模板编辑后继续使用旧会话快照，或明确新建会话，不能混合两套输入。清空历史不重开会话。

## 5. 公开与私有材料边界

私有原始记录保留在本地 `docs/vibe-coding/`，包括原始对话、精确用量来源、阶段登记和人工详细日志；只以代码路径说明，不将其作为公开文档链接。该目录及本机运行配置整体忽略，不上传公开仓库。

公开仓库提供脱敏的过程摘要、任务与提交对应关系、阶段 Token 汇总、统计截止和缺失范围。公开材料不包含本机绝对路径、个人身份、账号、会话或线程标识、密钥、原始提示中的私人信息、课件或论文原文件。

脱敏不意味着删除私有证据。公开摘要引用稳定的任务/工作编号；私有日志保留这些编号和原始来源映射。实验三需要更完整交互时，通过课程允许的受控渠道交接原始材料或专门脱敏导出，交接前复核敏感内容；不把公开摘要冒充完整原始对话。

公开发布前检查实际暂存文件，不能只依赖 `.gitignore`。工作状态始终区分“计划、进行中、已实现、已验证、失败、放弃”；本文全部 App 验收仍待执行。
