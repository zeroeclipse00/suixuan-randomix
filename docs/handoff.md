# 框架交接与组员任务

## 交接目标

先固定工程、共享领域接口、Room 持久化和转盘纵向流程，再按工具与功能拆分工作。队友可以在可构建基线上独立开发，减少同时改动 Gradle、数据协议和导航的冲突。

本轮不把 ST-01—ST-03 的所有验收项目宣称完成。实际验证范围与限制以本文件和[公开工作记录](process/work-log.md)为准。

## 框架边界

| 范围 | 当前实现边界 |
|---|---|
| 工程 | 单个 app 模块、固定依赖版本、官方 Gradle wrapper、运行入口 |
| 领域 | 五类工具的纯逻辑、共享输入校验、可注入随机源、转盘几何 |
| 数据 | 空草稿、整体版本保存、结果快照、幂等提交、提交序号历史、1000 条上限 |
| 转盘 | 明确载入示例、候选增删改、随机抽取、保存后动画、错误重试 |
| 历史 | 列表、快照详情、清空确认；完整筛选和分页交后续 |
| 设置 | 减少动画保存、跟随系统的浅深色样式；完整主题设置交后续 |
| 其他页面 | 硬币、骰子、灵感球、模板为明确标注的待开发页面，不伪装为已实现功能 |

## 第一次接手

1. 阅读[开发环境](development-environment.md)，从干净 clone 配置自己的 SDK/JDK，不复制别人的本地工具目录。
2. 运行 JVM 测试和 debug 构建；有设备时运行 instrumentation 测试。
3. 安装应用，载入四个示例选项并完成一次抽取，查看历史和快照。
4. 查看[架构契约](architecture.md)、[模块任务](modules.md)和下表，再认领单独模块。
5. 用独立分支和小提交开发，保留真实工作轨迹与用量来源；提交前检查隐私和相关回归。

## 推荐分工

| 工作包 | 可主要修改的文件 | 共用接口与完成条件 |
|---|---|---|
| 硬币与骰子 UI | `ui/tools/CoinScreen.kt`、`DiceScreen.kt`，可新增子组件 | 复用 DrawEngine/DecisionRepository；点数、动画、文字、历史一致 |
| 灵感球与字母模式 | `ui/tools/MagicBallScreen.kt`、后续 LetterScreen；新增答案配置仓储 | 不复制抽取提交逻辑；自定义空池不得回退；模式与答案需持久化 |
| 模板与历史完善 | `ui/tools/TemplatesScreen.kt`、`ui/history/HistoryScreen.kt`、新增模板实体和仓储 | 草稿与模板分离、明确版本、历史快照不可变；schema 变更有迁移 |
| 集成与交付 | `ui/AppViewModel.kt`、应用容器、共享导航和主题；文档与测试 | 由集成人统一维护共用入口，合并后回归所有工具 |

表中 Kotlin 路径都相对于 `app/src/main/java/com/suixuan/app/`。两人团队可合并前两个工作包，保留集成职责；三人团队可分别认领 UI 工具、模板数据、集成测试。

## 协作约定

- `domain/` 和 `DecisionRepository` 是共享边界。变更前先说明影响；优先扩展明确接口，不在各工具内部另建随机与历史机制。
- 新工具需要通过统一协调入口完成“冻结→生成一次→事务保存→展示”。不要在点击按钮、动画结束、重组或恢复时重复抽样。
- 新增数据表与字段时保存 Room schema，增加迁移/事务检查；不使用 destructive migration 清除队友或用户数据。
- 公共类型、Gradle、导航、共享 ViewModel 尽量由集成人维护，工具成员主要在独立页面和仓储中工作。
- 先补任务的输入、错误、恢复和验收，再提交实现。固定随机源只用于测试。
- 原始对话、逐调用账本、环境配置、截图和签名资料保持本地；公开仓库只包含脱敏工作摘要与聚合用量。

## 构建与验证记录

本轮实际通过 Debug APK 构建、26 个 JVM 测试、10 个 API 35 模拟器设备测试和 lint。模拟器已安装启动，并手工检查示例载入、结果/历史与强制结束进程后的恢复。lint 仍有 8 条固定依赖存在新版的升级提示，未修改版本迁就提示。详细条件见[验证结果](testing/framework-results.md)。

当前 `AppViewModel` 是转盘纵向流程的协调示例；`DrawEngine` 和 `DecisionRepository` 已支持其他结果类型。其他工具接入时，由集成人扩展统一抽取事件与各工具展示状态，再接到独立页面，避免每位成员复制一套保存/重试逻辑。完整跨工具恢复、答案与模板状态仍属于后续工作。
