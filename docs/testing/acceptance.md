## 3. Given / When / Then 关键用例

### TC01 输入、重复与顺序（AC02、AC03）

- **Given：** 已保存候选“面馆”“食堂”，按位置 0、1 显示。
- **When：** 编辑首项、取消一次编辑、删除首项再新增；并分别提交空白、超长、规范化同名项和第 21 项。
- **Then：** 取消不落库；编辑保留 ID，删除重排，新增在末尾；非法值保留表单与字段提示；列表与转盘顺序相同，未出现半份写入。

### TC02 空池与单项（AC02、AC08）

- **Given：** 分别为空池与只有一个合法候选/答案的池。
- **When：** 尝试抽取。
- **Then：** 空池不调用随机源、不写历史并提供新增入口；单项不消耗随机源，返回唯一项且只写一条历史，直接揭示。

### TC03 转盘概率与角度（AC04）

- **Given：** N 为 1、2、3、7、20，使用固定源逐个返回所有合法索引；输入有明确顺序，起始旋转角含 0、负角和多圈角。
- **When：** 生成结果并按公式计算终点，在 UI 实际渲染。
- **Then：** 每个结果都来自相应快照，中心对准指针；文字、选中 ID、历史一致；扇区等宽，动画不调用随机源。浮点比较使用事先规定的合理误差。

### TC04 快速连点与旧回调（AC05）

- **Given：** Ready，仓储提交可由测试控制延迟。
- **When：** 同一帧及 Saving/Animating 中连续点击；完成后触发旧动画回调。
- **Then：** 同步门禁只受理一个操作，随机源一次、历史一条；旧回调不能新提交或改变新操作。下一次 Ready 的主动点击才生成新 ID。

### TC05 已知保存失败后重试（AC05、AC14）

- **Given：** 已生成 envelope，首次提交明确回滚。
- **When：** 页面显示 SaveError，随后恢复存储并点击重试保存。
- **Then：** 首次无成功动画/历史；重试保存相同 ID 和结果，随机调用总次数仍为一次，最终历史一条。

### TC06 已提交但返回中断（AC05、AC14）

- **Given：** 事务已提交，调用返回前模拟中断，UI 尚未确认成功。
- **When：** 协调器按 draw_id 查询；另测查询自身也失败。
- **Then：** 查到时恢复原记录，不再抽样或重复插入；查询失败保持未知提交错误，不能当“不存在”重新写入。

### TC07 模板与答案快照（AC10、AC12）

- **Given：** 从模板版本 1 套用并完成抽取；自定义答案也完成一条结果。
- **When：** 编辑草稿、更新模板到版本 2、删除来源模板、编辑/删除旧答案。
- **Then：** 草稿改动不静默更新模板；旧记录仍显示版本 1 与当时文本/顺序；当前来源删除只影响后续更新入口，不改过去。测试深复制后修改原集合也不能改变已建请求。

### TC08 编辑版本冲突（AC03、AC10）

- **Given：** 两个编辑动作基于相同草稿或模板版本。
- **When：** 第一个保存成功，第二个用旧 expectedRevision 提交。
- **Then：** 第二个返回 Conflict，不覆盖新数据；用户表单保留并可重新载入，版本只按成功修改增加。

### TC09 提交 ID 内容冲突（AC05）

- **Given：** 某 draw_id 已保存合法请求和结果。
- **When：** 用同内容重复提交，再用同 ID 的不同请求/结果提交。
- **Then：** 同内容返回原记录；不同内容拒绝且数据库不变，不采用覆盖更新。

### TC10 骰子独立数组与总和（AC07）

- **Given：** 数量分别为 1、2、3，固定源序列覆盖 1、6 及混合点数。
- **When：** 掷骰并保存，然后改变当前数量。
- **Then：** 各骰按顺序消费独立随机值，数组长度正确，点阵和数值一致，总和由数组计算；旧历史数量不随当前配置变化。

### TC11 答案模式、空池与单项（AC08、AC13）

- **Given：** 自定义池为“散步”“听音乐”，默认池另有答案。
- **When：** 切到自定义、抽取、重启、删除到剩一个再删空，随后切回默认。
- **Then：** 自定义结果只来自两条答案；模式重启保留，单项正常，空池禁用且不回退；默认池始终保留，切换自身不写历史。

### TC12 字母边界与模式隔离（AC09、AC13）

- **Given：** 普通转盘有已保存候选。
- **When：** 切字母模式，用固定源输出首尾索引，回到候选模式。
- **Then：** 分别为 A、Z，历史标记字母工具；原候选 ID、文本、顺序不变，模式切换不产生额外历史。

### TC13 生命周期与提交边界（AC13、AC14）

- **Given：** 分别停在提交前、已提交未揭示、Animating 和 Revealed。
- **When：** 旋转屏幕、切后台、离开再返回；分别模拟进程终止后重启。
- **Then：** 活跃进程保留同一操作；已提交结果从数据库恢复且不重抽；提交前中断不宣称成功，已保存草稿仍在。切后台/离开可直接结束装饰展示，不能留下永久忙状态。

### TC14 清空历史与迟到事件（AC11、AC14）

- **Given：** 已揭示结果，模板/答案/草稿存在；另有忙操作时先检查清理被阻止。
- **When：** 结果揭示后确认清空，再发出旧动画回调或旧页面重组，最后重启。
- **Then：** 历史保持空，不被迟到事件重建；模板等不变，当前内存结果可显示但重启不从隐藏副本复活。

### TC15 稳定顺序与容量（AC11）

- **Given：** 已有 1000 条合法记录，若干时间戳相同，并模拟系统时间回调。
- **When：** 再提交一条。
- **Then：** 按 sequence 新记录在最前，只有最早一条被裁剪，容量 1000；不因时间相同丢失其他记录，裁剪与提交原子完成。

### TC16 不重复会话与回滚，P1（AC20）

- **Given：** 会话有三个稳定 ID，且保留来源模板。
- **When：** 逐个抽取；中间注入提交失败、旧会话版本冲突；之后抽尽、重启、重开，并清空历史。
- **Then：** 成功结果与剩余池同事务；失败/冲突时两者都不变且不自动重抽；一轮无重复，耗尽禁用，重开才恢复全池；模板不被删项，清历史不重开会话。

### TC17 减少动画与可访问性（AC15、AC16）

- **Given：** 相同测试输入与固定源，分别开启/关闭减少动画；设备使用大字体。
- **When：** 在每个工具执行操作并读屏、使用返回和键盘。
- **Then：** 结果与随机调用次数一致；完整结果可读，主操作可触达，不只靠颜色区分；读屏可以理解工具、按钮和结果。

### TC18 过程、公开隐私与交付（AC17—AC19）

- **Given：** 有真实工作记录、用量来源与准备发布的暂存文件。
- **When：** 重复同步并生成公开摘要，审查提交内容，按固定版本执行复现与交付核对。
- **Then：** 不重复计数，未知不填零，子代理与阶段范围明确；公开内容无本机路径、身份/会话标识、密钥和原始附件，私有证据仍保存；文档、APK、视频与报告指向一致版本，随机结果无需逐次相同。

## 4. 执行记录与完成条件

每次执行记录：AC/TC、任务与主阶段、提交、设备/系统/API 级别、命令或操作、预期、实际结果、证据、问题/修复及回归。公开证据使用仓库相对路径或实际公开链接，原始详细日志只在私有记录保留映射。

未运行写“未验证”，环境无法执行写具体限制；失败保留真实现象与修复，不修改预期以迁就错误。只报告本应用在指定条件下的结果，不外推为 AppForge 101 项任务的模型成功率。

首版完成条件是 P0 全部通过，缺陷与限制真实披露，构建/功能/稳定性/过程各有证据，且无阻断演示与数据正确性的未解决问题。P1/P2 不启动不阻止首版，但若演示和报告宣称已实现，就必须完成对应验收。
