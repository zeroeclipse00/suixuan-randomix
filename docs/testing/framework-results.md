## 已发现并处理的问题

- PowerShell 将 `--info` 当作通用参数：构建辅助脚本改为直接转发未绑定参数。
- Windows 转换缓存目录重命名失败：保留下载缓存，停止项目 daemon 后重试；限制 worker 并关闭文件监视。未关闭系统安全软件或删除 SDK。
- 设备测试依赖一次 TLS 握手中断：保留失败日志，再次从官方仓库获取后完成测试。
- 旧恢复查询可能覆盖新抽取：增加活动操作 ID 检查，并补充可控延迟回归测试。
- 一次恢复查询失败会结束历史订阅：将恢复错误与长期订阅分开处理，补回归测试；协程取消继续正常传播。
- 小屏首页主按钮落在滚动区：改为固定主操作区与随窗口缩放的转盘，经实际截图检查。

## 限制与后续

- ST-01/02 的基础设施与 ST-03 最小流程可交接，不能据此宣称三个阶段全部验收完成。
- 硬币、骰子、灵感球和字母的领域逻辑已有测试；它们的产品页面及完整配置未接入。
- 模板、答案池管理、历史筛选/分页、完整主题设置及全部无障碍/生命周期场景仍待实施。
- 尚未完成全部 P0 用例、真机验证、多 API/尺寸矩阵或课程最终视频报告。
- 依赖采用已验证的固定版本；升级应另建任务并重新运行相关检查。
